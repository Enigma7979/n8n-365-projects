# 001 - المنبه الذكي الصباحي

## الوصف
نظام آلي يرسل مهامك اليومية إلى تيليجرام كل صباح الساعة 8:00. المهام مرتبة حسب أيام الأسبوع مع اقتباسات تحفيزية عشوائية.

## الأدوات المستخدمة
- N8N
- Telegram Bot
- JavaScript / Python

## طريقة الاستخدام
1. حمّل ملف smart-morning-notifier.json.
2. استورده في N8N.
3. أضف توكن بوت تيليجرام و Chat ID.
4. خصص المهام والاقتباسات من عقدة Code/Python.
5. فعّل الـ Workflow.

## الجدول
- من الاثنين إلى الأحد الساعة 8:00 صباحاً.

## التخصيص
عدّل مصفوفة tasks في عقدة Code لتناسب روتينك الأسبوعي. غيّر الاقتباسات كما تحب.

## إعداد الأمان قبل التشغيل
- أنشئ بوت Telegram خاصًا بك عبر [BotFather](https://t.me/BotFather)، ثم أنشئ Telegram API Credential داخل n8n واختره في عقدة **Send a text message**.
- استبدل `YOUR_TELEGRAM_CHAT_ID` بمعرّف محادثتك أنت. لا تستخدم توكن أو Chat ID لشخص آخر.
- لا تضع توكن البوت داخل ملف JSON أو GitHub. ملف المشروع العام لا يتضمن Credentials جاهزة.
- إذا سبق نشر توكن حقيقي، ألغِه وأصدر توكنًا جديدًا؛ حذف النص من آخر Commit لا يمحوه من سجل Git.
- بعد الاستيراد، تأكد من الجدولة والمنطقة الزمنية واختبر الإرسال قبل التفعيل.
