# Setup checklist

- Import workflow JSON into n8n.
- Configure new Telegram API credentials on both Telegram nodes.
- Configure Groq API credentials on the Groq model node.
- Confirm the selected Groq model is available.
- Start a manual Telegram Trigger test, then message your bot.
- Confirm the three Reel ideas are returned.
- Activate only after a successful test.
- Never publish bot tokens, API keys or chat IDs.
