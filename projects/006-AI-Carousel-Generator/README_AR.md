# 006 — مولّد سلايدات الكاروسيل بالذكاء الاصطناعي

[English](README.md) · [ملف المشروع](workflow/006-AI-Carousel-Generator.public.json)

مشروع n8n يحوّل **أي موضوع ترسله إلى بوت Telegram الخاص بك** إلى **7 صور PNG عمودية بمقاس 1080 × 1920** باللغة العربية، باستخدام Groq وChromium/Browserless. يظهر عنوان مرتبط بموضوعك، من دون اسم المشروع أو علامة مائية أسفل السلايدات.

## ما الذي تحتاجه؟
- حساب n8n خاص بك.
- بوت Telegram تنشئه من [BotFather](https://t.me/BotFather) و**توكن خاص بك**.
- مفتاح Groq API خاص بك من [Groq Console](https://console.groq.com/keys).
- خدمة Chromium/Browserless **خاصة بك** تدعم المسار `/function` لتحويل SVG إلى PNG.
- متغير `CAROUSEL_RENDERER_URL` على خادم n8n بقيمة عنوان خدمتك الكامل، مثال توضيحي: `http://YOUR_RENDERER_HOST:8080/function`. **لا تستخدم هذا المثال كما هو**.

## خطوات التشغيل
1. نزّل [ملف JSON المنظّف](workflow/006-AI-Carousel-Generator.public.json) واستورده في n8n.
2. أنشئ Telegram API Credential باستخدام **توكن البوت الخاص بك** واربطه بالعقد: `006 Telegram Topic` و`Telegram - Review Draft` و`006 - Send PNG to Telegram`.
3. أنشئ HTTP Header Auth Credential لـ Groq: اسم الهيدر `Authorization` وقيمته `Bearer YOUR_GROQ_API_KEY`. اربطه بعقدة `Groq - Generate Arabic Carousel Copy`.
4. شغّل خدمة Browserless/Chromium الخاصة بك. ضع عنوانها في متغير `CAROUSEL_RENDERER_URL` على خادم n8n، وتأكد أن خادم n8n يستطيع الاتصال بها. إذا كان n8n يمنع قراءة متغيرات البيئة، استبدل تعبير URL في عقدة التصيير بعنوان خدمتك.
5. تأكد من توفر نموذج `allam-2-7b` لدى Groq أو اختر نموذجًا مدعومًا، وتأكد من توفر خطوط عربية في بيئة Chromium.
6. احفظ وفعّل المشروع، ثم أرسل موضوعًا إلى **بوتك أنت**. يجب أن تصلك سبع صور PNG.

## رقم Telegram والمجموعات
رقم المحادثة `chatId` يُقرأ تلقائيًا من رسالة Telegram الواردة؛ **لا يوجد رقم مجموعة أو رقم حساب خاص بالمطور في القالب**. إذا أردت حصر الاستخدام عليك أو على مجموعتك، أضف قائمة سماح بمعرّفات المستخدمين أو المحادثات **الخاصة بك** قبل نشر البوت للعامة.

## كيف يعمل؟
`Telegram → إعداد الموضوع → Groq → تقسيم 7 سلايدات → تصميم SVG → Chromium PNG → التحقق → إرسال الصور إلى Telegram`

يوجد مسار إضافي لإرسال مسودة نصية. الصور قابلة للاستيراد إلى **Canva Free**، لكن المشروع **لا يتصل بواجهة Canva API** ولا ينشئ عناصر Canva قابلة للتحرير مباشرة.

## الخصوصية والأمان
- حذفنا من الملف العام مراجع بيانات الاعتماد الأصلية، ومُعرّفات Telegram الخاصة، وعنوان Railway الداخلي، ومُعرّفات Webhook.
- يجب على كل مستخدم إضافة **توكن Telegram الخاص به** و**مفتاح Groq الخاص به** و**عنوان Chromium الخاص به**.
- لا تنشر ملف `.env` الحقيقي أو كلمات المرور أو رموز API أو عناوين الخوادم الخاصة أو سجل التنفيذ.
- احمِ خدمة التصيير بشبكة خاصة أو ضوابط وصول، وأضف تحديدًا للمستخدمين المسموح لهم بالتعامل مع البوت.
- القالب **غير مفعّل افتراضيًا**؛ اختبره بعد استيراده.
- إذا سبق نشر سر حقيقي في GitHub، يجب تغييره؛ حذفه من نسخة لاحقة لا يكفي.
